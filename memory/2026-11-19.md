# 2026-11-19 工作日志

## 创业板数据源探查（为第一个页面 ERP 页补 399006）

背景：`web/index.html`（股债性价比页）契约里记录创业板指（399006）暂缺。本轮实测候选数据源，结论如下。

### 关键结论
- 创业板指属于**国证/深证指数体系**，不是中证体系 → 项目主源中证官网 `index-perf` 对 399006 返回 0 条，这是"暂缺"的根因。
- 实测不可用的源：
  - `ak.stock_zh_index_value_csindex("399006")` → HTTP 404
  - `ak.stock_index_pe_lg("创业板指")` → KeyError，乐咕只支持创业板50（且月频）
  - `ak.stock_market_pe_lg("创业板")` → **能跑通但月频**（16 年仅 198 行，间隔中位数 30 天，99% 采样在月末），且是「平均市盈率」等权口径（最新 32.93），返回"指数"点位 2922.55 更像创业板综指/板块而非 399006 本身 → 频率+口径+标的三重不符，无法用于日频 ERP。
  - 东财 `RPTA_INDEX_PE` → 报表不存在
  - 本机未装 tushare、无 Tushare token
- 可用方向（尚未落地）：
  - Tushare `index_dailybasic(ts_code="399006.SZ", fields="...,pe_ttm")` 日频，需 400 积分 token
  - 聚合估值检索可返回日频 PE(TTM/LYR) 序列，可考虑抓成 `data/pe_399006.csv`（date,close,pe 三列，与现有 pe_*.csv 同格式）挂进 config
  - 国证官网 cnindex / ETF.run 有 PE 但无现成历史下载，适合做校验基准

### 创业板指估值快照（2026-11 中旬，多口径，来自专业检索）
- 整体法 TTM PE 26.26、近5年分位 8.18%、PB(LF) 3.69、股息率TTM 1.32%（数据截止 2026-11-18）
- 国证官网滚动 PE 24.48（11-10，一手）；ETF.run 等权 PE 42.93、分位 29.78%（11-16）
- 口径差异极大，页面 ey=100/PE 对口径敏感，接入前必须统一为整体法/TTM

### 落地结果（用户拍板：创业板50 就50，标清楚即可，总比没有强）
- 用户截图质疑"月频判断"，实测澄清：当前 akshare `stock_index_pe_lg` 上游 API 源头就是月频（无降频环节），截图的 4805 行日频来自旧版/其他入口，非当前接口。
- 用东财 `stock_zh_index_daily_em` 拉全历史被代理限流；改腾讯源 `stock_zh_index_daily_tx("sz399673")` 拿到 3021 行日频收盘价（2014-06 至今）。
- **生成 `data/pe_399673.csv`**：乐咕月频整体法静态 PE（`lyrPe`）做锚点 × 腾讯日频收盘价比例插值 → 日频 PE。锚点日偏差=0，PE 范围 30.8–132.8，无负值。
