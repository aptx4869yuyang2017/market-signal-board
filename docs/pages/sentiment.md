## 页面定位

回答一个问题：**市场情绪离「大众都在犯错」的极端还有多远？**

- 读者：本人。与 ERP（贵不贵）、成交额（挤不挤）、杠杆资金（仓位满不满）并列，构成第四个维度。
- 观点前提：市场总体会犯错。当多数参与者一致悲观（现金高、融资快速偿还、开户冰点、外资不关注）时，反而接近左侧分批建仓窗口；一致乐观时则降低买入节奏。
- 不做择时预测。四项指标都是**情绪刻度**，不是买卖信号；单一指标极值不等于反转。
- 与杠杆资金页分工：杠杆页看**存量杠杆率**（2%/3%/4% 长期区间）与融资买入占比；本页看**融资余额 20 日变化速度**，回答「是不是在恐慌性平仓」。

## 数据契约

顶层结构：

```json
{
  "asof": "2026-11-19",
  "updated": "2026-11-22 19:00",
  "composite": {},
  "stats": {"fund": {}, "margin": {}, "account": {}, "north": {}},
  "series": {"fund": {}, "margin": {}, "account": {}, "north": {}},
  "notes": []
}
```

### `composite`

| 字段 | 含义 |
|---|---|
| `score` | 四项「温度」等权平均，0–100（0 冰点 / 100 过热），保留 1 位 |
| `tier` / `note` / `color` / `bg` / `border` | 命中 `sentiment.score_tiers` 的档位与配色 |

四个 `stats.*` 子对象均带 `score` / `score_tier` / `score_note` / `score_color` / `score_bg` / `score_border`，用于卡片上色，页面不自定义阈值色。

### `stats.fund`

| 字段 | 单位 | 含义 |
|---|---|---|
| `asof` | str | 最新季报日 |
| `cash` / `cash_prev` / `cash_chg` | % / pp | 按净资产加权的样本基金现金占净值比、上季度值、环比 |
| `cash_pct` | % | 现金比例在 2014 以来各季度的分位（越高子弹越足 / 越冷） |
| `score` | 0–100 | 本页统一温度，此处等于 `100 − cash_pct` |
| `funds` | int | 参与最新季度加权的基金数量 |
| `stock_pos` / `stock_pos_asof` / `stock_pos_pct` | % / str / % | 乐咕周度全样本股票仓位估算（辅助，不进综合分） |

### `stats.margin`

| 字段 | 单位 | 含义 |
|---|---|---|
| `asof` | str | 最新两融交易日 |
| `balance_wan` | 万亿 | 沪深融资余额 |
| `chg20` | % | 融资余额相对 20 个交易日前的变化率 |
| `chg20_pct` | % | 该变化率在 2015 以来的分位 |
| `drawdown` | % | 相对近 252 交易日高点的回撤 |
| `tier` / `note` / `color` | str | 命中 `sentiment.margin_tiers` 的档位 |
| `score` | 0–100 | `100 - chg20_pct` |

### `stats.account`

| 字段 | 单位 | 含义 |
|---|---|---|
| `asof` | str | 最新月份（YYYY-MM） |
| `new_a` | 万户 | 上交所 A 股个人投资者当月新开户数 |
| `mom` / `yoy` | % | 环比、同比 |
| `pct` | % | 2021-12 以来分位（越低越悲观） |
| `score` | 0–100 | `100 - pct` |

### `stats.north`

| 字段 | 单位 | 含义 |
|---|---|---|
| `asof` | str | 最新交易日 |
| `deal_ma20` / `deal_ma5` | 亿元 | 沪股通 + 深股通成交总额 20 日 / 5 日均（图上展示的绝对额） |
| `rel_activity` | 比值 | 相对活跃度 = `deal_ma20 / deal_ma250`（近 20 日均额 ÷ 近 250 日均额），已去长期增长趋势 |
| `deal_pct` | % | 相对活跃度在近 5 年的分位（越低越冷清） |
| `score` | 0–100 | 等于 `deal_pct`（去趋势后的相对活跃度分位，越低越冷） |
| `net_disclosed` | bool | 恒为 false：2024-08-19 起官方不再披露北向每日净买入 |

### `series`

`fund`：`dates` / `cash`（%）。`margin`：`dates` / `chg20`（%）/ `drawdown`（%）。
`account`：`dates` / `new_a`（万户）。`north`：`dates` / `deal_ma20`（亿元）/ `rel_activity`（相对活跃度比值，前 250 日为 null）/ `bands`（五档背景带：`lo` / `hi` / `color` / `label`，由相对活跃度的全样本分位点映射 `score_tiers` 得到）。
日期均为 `YYYY-MM-DD`（开户为 `YYYY-MM`）。

`benchmark`：`dates` / `close`，中证全指（000985）日频点位，只读复用 `data/turnover_daily.csv`（由 `turnover.py` 抓取维护），不参与任何分位与温度计算。缓存缺失时为空数组，页面自动隐藏辅助曲线。tooltip 按「当日或之前最近交易日」对齐取点位。

`temperature`：`dates` / `score` / `fund` / `margin` / `account` / `north`，四项温度的历史序列，日频（0 冰点 / 100 过热）。以融资余额日频为轴，基金（季度）与开户（月度）前向填充为当时最新公布值；各项分位逐点只算截至当日的历史（无未来函数），窗口与卡片一致。起点为开户样本满一年（2022-01），末端的 `score` 与四项分用当期值覆盖，保证与 `composite.score` 严格一致。

顶层 `tiers`：`max` / `label` / `color` 的档位数组，来自 `config.yaml` 的 `sentiment.score_tiers`，供温度图底色与分界线使用，页面不自定义档位色。

### `notes`

字符串数组，四条，分别说明基金现金、融资余额、开户数与北向代理的当前读数与局限。

## 交互契约

| 操作 | 结果 |
|---|---|
| 悬浮任一图 | tooltip 显示日期、指标数值与对齐后的中证全指点位；日期取数据点原始字符串（月度 `YYYY-MM` 不补 1 日） |
| 悬浮北向图 | tooltip 显示日期与命中的档位（由 `bands` 按 ratio 定位）、相对活跃度（3 位小数）、当日绝对成交额（亿元）与指数点位 |
| 点「中证全指」按钮 | 单独开关当前图的右轴灰色辅助线，四图互不影响、不影响 tooltip 之外的结论 |
| 点 1 年 / 3 年 / 5 年 / 全部 | 五张图（含温度趋势）各自按自身日期序列独立缩放，不联动（频率不同：日 / 季度 / 月 / 日） |
| 温度图图例 | 默认只显示综合温度线；勾选可叠加四项分（基金 / 融资 / 开户 / 北向）对比谁在驱动温度 |
| 每张图右下角 | 固定标注数据源水印（ECharts graphic，随图片导出） |

| 窗口 resize | 四张图自适应 |

| 导出图片 | 每张图右上角 toolbox 导出 2x PNG |

默认区间为「3 年」（四张图各自按自身日期序列取最近 3 年）；卡片与温度始终用全样本分位，图表缩放只改变可视区间，不影响任何阈值与结论。

## 计算契约

### 市场温度

```text
fund.score   = 100 − 基金现金比例分位（现金越多越冷）
margin.score = 融资余额 20 日变化率分位（跌得越快越冷）
account.score= 新增开户数分位（开户越冷越冷）
north.score  = 北向相对成交活跃度分位（20日均额/250日均额，相对近期萎缩越冷）
composite    = 四项等权平均；0 = 冰点 / 极端悲观，100 = 过热 / 贪婪
```

分位统一为「样本中低于当前值的比例」，保留 1 位小数。档位按温度从低到高排列（0 极端悲观 → 100 情绪过热），阈值在 `config.yaml.sentiment.score_tiers`。北向分位的输入经去趋势处理：成交额长期增长（2018 年 205 亿 → 2026 年 3187 亿）会让绝对额分位长期贴在 80+，「极端悲观」档 0 次触发；改用相对活跃度后分位覆盖 0–100，档位恢复区分度。

### 基金现金比例

```text
现金比例% = Σ(基金现金占净值比 × 基金净资产) ÷ Σ(基金净资产) × 100
```

- 样本为 `sentiment.fund_codes` 中 25 只主动权益基金，来源为天天基金 F10 资产配置明细（定期报告口径，季度更新）。
- 拿不到数据的基金该季度跳过；不足 5 只的季度不出数。
- 辅助项「股票仓位」来自乐咕 `fund_stock_position_lg()` 周度全样本估算，只作方向参照，不进综合分。

### 融资余额变化

```text
chg20% = 融资余额(t) ÷ 融资余额(t−20) − 1
drawdown% = 融资余额(t) ÷ 近 252 交易日最高融资余额 − 1
```

- 复用 `data/leverage_daily.csv`（东方财富融资融券历史合计，日频），不重复抓数。
- 档位按 `chg20`：≤−8% 恐慌平仓、−8%~−4% 快速去杠杆、−4%~+2% 震荡、>+2% 加杠杆。

### 新增开户数

- 上交所「上证统计月报 · 投资者」`commonQuery.do`，sqlId `COMMON_SSE_TZZ_M_STOCK_ACCT_C`，字段 `A_PERSON`（A 股个人新开户，万户）。
- MDATE 传 `YYYYMM` 返回当年 1 月至该月的累计表；未来月份返回空，脚本从 12 月往前找第一个有数据的月份。表里未来月份值为 0，必须过滤。
- 样本从 2021-12 起，分位窗口 5 年。

### 北向活跃度

- 东方财富 `RPT_MUTUAL_DEAL_HISTORY`，`MUTUAL_TYPE` 001（沪股通）+ 003（深股通），字段 `DEAL_AMT` 按 /100 换算为亿元。
- 自 2024-08-19 起交易所不再披露北向每日净买入/净卖出，历史净流向与当前活跃度**混合不可比**；本页只展示成交总额，不重建净流入序列。
- 温度用去趋势后的相对活跃度：`rel_activity = deal_ma20 / deal_ma250`，其中 `deal_ma250` 由 `config.yaml.sentiment.north_trend_days`（默认 250）控制。北向数据从 2018-01-29 起，250 日均线在 2019 年初才有值，温度序列起点 2022-01 不受影响。
- 去趋势效果验证（2022-01 至今 1181 日）：北向分位均值 83.6→43.4、最低 23.1→0.1；与未来 60 日收益 IC −0.084→−0.133；综合温度 IC60 −0.116→−0.138、IC120 −0.124→−0.168；温度地板 29.2→13.3；「极端悲观」档触发 0→43 次。相对分位 <20 的冷信号后续 60 日胜率 77%、均涨 +9.11%。

## 文案与配色

- 悲观 = 冷色（蓝 `#2f6f9f` / `#5b8db8`），中性 = 黄 `#c8971b`，乐观/过热 = 暖色（橙 `#e0703a` / 红 `#c0392b`）。
- 基金现金保留 2 位小数，融资余额 2 位（万亿），chg20 / 开户环比 / 同比 1 位，开户数 2 位（万户），北向成交额 0 位（亿元），分位 1 位。
- 页头副标题固定包含数据截止与更新节奏；北向卡片必须写明「净流向已停止披露，活跃度代理」。
- 综合档位文案强调「情绪刻度，不是买卖信号」。

## 边界

- 基金现金是**季度快照**，且为 25 只主动权益基金的加权样本，不等于全市场公募平均；季报披露有 15 个工作日时滞。
- 融资余额变化是**速度**指标，快速下降可能来自强平，也可能来自政策/季节性因素，须与杠杆页的存量档位交叉验证。
- 上交所开户数据只有 2021-12 以后月度值，5 年分位样本较短；开户数受开户政策与佣金竞争影响。
- 北向只有成交总额（活跃度），没有方向；不能用本页数据判断「外资在流入还是流出」。
- 免费源无 SLA；页面为静态快照，运行脚本才更新；仅适合个人监控，不构成投资建议。
