## 页面定位

回答一个问题：**市场杠杆加到了什么位置？**

- 读者：本人，与「两市成交额」的拥挤度交叉验证。
- 主信号：**杠杆率** = 沪深融资余额 ÷ 沪深 A 股流通市值，按 2% / 3% / 4% 的长期经验区间定档。
- 辅助信号：**融资买入占比** = 近 5 日融资买入额合计 ÷ 同 5 日成交额合计，看流量活跃度。
- 与成交额页的分工：成交额页回答「交易有多拥挤」，本页回答「仓位加到了多满」。两者同向（高换手 + 高杠杆）风险更实在；背离（高换手 + 低杠杆）更接近情绪脉冲。
- 杠杆档位是风险刻度，不是买卖信号：冰点不等于立刻反转，过热也不等于立刻下跌。

## 数据契约

顶层结构：

```json
{
  "asof": "2026-11-11",
  "updated": "2026-11-17 20:50",
  "stats": {},
  "series": {},
  "log": [],
  "bands": []
}
```

### `stats`

| 字段 | 类型 / 单位 | 含义 |
|---|---|---|
| `balance` | float，亿元 | 沪深融资余额 |
| `balance_wan` | float，万亿 | 同上，用于卡片 |
| `balance_chg_pct` | float，% | 融资余额较上周变化 |
| `ratio` | float，% | **杠杆率** = 融资余额 ÷ 流通市值 × 100 |
| `ratio_chg` | float，pp | 杠杆率较上周差 |
| `ratio_pct` | float，% | 杠杆率在 2014 以来各周的辅助分位 |
| `band` / `band_range` / `band_note` | string | 命中的档位名 / 区间文案 / 说明句 |
| `color` / `bg` / `border` | string | 档位色及其 8% 底、33% 边框 |
| `buy_share` | float，% | **融资买入占比（5 日）** |
| `buy_share_chg` | float，pp | 较上周差 |
| `buy_share_pct` | float，% | 融资买入占比在 2014 以来的分位 |
| `circ_wan` | float，万亿 | 最新交易日流通市值 |
| `ymax` | float，% | 图表左轴上限 |

### `series`

`dates`、`ratio`（%）、`balance`（亿元）、`buy_share`（日频，%）、`buy_ma20`（20 日均，%）、`circ`（万亿）。

### `log`

近 12 周，字段 `date` / `balance`（亿） / `ratio`（%） / `band` / `buy_share`（5 日，%）。

### `bands`

直接来自 `config.yaml` 的 `leverage.bands`，用于底色、阈值线与台账胶囊。

## 计算契约

### 杠杆率

```text
杠杆率% = 沪深融资余额 ÷ 沪深 A 股流通市值 × 100
```

- 分子：沪深两融汇总的融资余额（不含融券），单位亿元。北交所体量不足 1%，未计入。
- 分母：**流通市值**，不是总市值。总市值包含大量暂不流通股份，会系统性稀释杠杆率；融资盘能买的只有流通股，用流通市值才能跨年份比较，也才和 2% / 3% / 4% 的长期经验区间对齐。
- 两者都取**日频**：东方财富融资融券历史合计（`RPTA_RZRQ_LSHJ`），一次请求拿到 `RZYE`（融资余额）、`RZMRE`（融资买入额）、`LTSZ`（沪深 A 股流通市值），2010-03-31 至今连续无缺口。
- 该接口自带 `RZYEZB`（融资余额占流通市值比），用于自校验：`ratio` 与它的偏差应恒为 0.00pp。
- 官方值核对：2015-06-12 `LTSZ` 57.52 万亿 = 上交所 35.85 万亿 + 深交所 21.68 万亿（交易所月度/每日市价总值），口径一致。
- 为什么不再用「月末锚点 + 指数插值」：早期没有日频流通市值，只能用月度官方值加指数衔接，2015 年 6 月、2021 年 2 月这类剧烈波动月份误差可达数个百分点；换成日频流通市值后不需要任何插值。

### 融资买入占比

```text
融资买入占比% = 近 5 个交易日融资买入额合计 ÷ 同 5 个交易日成交额合计 × 100
```

- 流量口径，对情绪边际变化比存量杠杆率更敏感；5 日合计相除，避免单日噪声。
- 图上另画 20 日均线，仅辅助看趋势。
- 成交额沿用中证全指日频成交额，与成交额页同源。
- 两融偶尔比行情晚一天：余额与流通市值前向填充，买入额不填，避免虚增流量。

### 档位（长期经验区间，不是分位）

| 杠杆率 | 档位 | 颜色 | 含义 |
|---|---|---|---|
| < 2.0% | 冰点 | 蓝 `#3b6ea5` | 杠杆资金大量离场，情绪极度悲观，历史级别底部区域 |
| 2.0–3.0% | 中性 | 黄 `#c8971b` | 震荡磨底，机会集中在局部，整体风险可控 |
| 3.0–4.0% | 活跃 | 橙 `#e0703a` | 杠杆资金明显活跃，局部过热风险上升 |
| ≥ 4.0% | 过热 | 红 `#c0392b` | 历史级别杠杆过热区，风险大于机会 |

档位来自 `config.yaml` 的 `leverage.bands`（`max` 为开区间上界）。**不用分位定档**：分位会被样本区间和杠杆中枢漂移带偏，绝对阈值才可跨年份比较；分位只在卡片上作辅助信息。

### 为什么独立成页

换手率是「交易有多拥挤」，杠杆率是「仓位加到了多满」。两套坐标系、两种判读方式（分位 vs 长期绝对区间），塞在同一页会让读者把两者混成一个信号。独立成页后各自保持完整的时间轴与图例。

## 文案与配色

### 命名

| 场景 | 用词 |
|---|---|
| 存量指标 | **杠杆率**（融资余额 ÷ 流通市值） |
| 流量指标 | **融资买入占比（5 日）** |
| 档位 | 冰点 / 中性 / 活跃 / 过热（固定四档，不写「分位」） |
| 禁用 | ~~融资余额占比~~（分母不明）、~~杠杆分位~~（档位不是分位） |

### 文案

- 杠杆率两位小数，融资余额两位小数（万亿），分位一位小数，流通市值一位小数（万亿）。
- 副标题固定包含：存量/流量口径、数据截止、更新频率。
- 页脚必须保留：杠杆率口径（为什么用流通市值）、融资买入口径、四档说明、数据来源、与成交额页的配合方式。
- 图表截止日与页面数据截止分开标注；两融通常晚 1 个交易日。

### 颜色语义

| 元素 | 规则 |
|---|---|
| 杠杆率折线 | `#c0392b` |
| 融资余额折线（右轴） | `#c9a06a`，带 10% 面积填充 |
| 融资买入占比 | `#3b6ea5`；20 日均线 `#9aa0a6` 虚线 |
| 杠杆区间底色 | 档位色 + `10`（约 6% 透明度），阈值线 `#d6d1c8` 虚线 |
| 杠杆率卡 / 档位卡 | 按 `stats.color` 上色（`bg` / `border`） |
| 较上周 | 上行暖色 `#c0392b`，下行冷色 `#3b6ea5`，持平灰 |

## 边界

- 两融只含沪深，未计北交所；北交所融资余额占比不足 1%，对档位判断无实质影响。
- 融资余额是**存量**，含未偿还的融资买入持仓；融资买入额是**流量**，两者不能混用。
- 流通市值、融资余额同为东方财富转发的交易所日频汇总，口径一致；单日 0 值与负值视为缺失，余额前向填充、买入额不填。
- 杠杆率 2015-07-03 峰值 4.70%，2024 年初低点约 1.73%，2026-11-11 为 2.49%。
- 档位是长期经验刻度，不是择时信号：冰点可能持续很久，过热也可能再创新高。
- 两融数据通常比行情晚 1 个交易日，页面用 `#lv-asof` 单独标注，不能拿行情截止日代替。
- 两融接口缺失/异常时，`leverage.run()` 抛错被 `turnover.run()` 捕获，杠杆页跳过生成，成交额页照常生成。
- 免费源无 SLA；页面为静态快照，运行脚本才更新。
