## 页面定位

回答一个问题：**现在股票相对债券，贵还是便宜？**

- 读者：本人，每周做一次仓位与定投决策参考。
- 主信号：ERP 的 10 年便宜度分位 + 估值分位双确认。
- 不承担：择时买卖点、个股选择、风险预算。
- 页面是**离线静态快照**，不请求接口；打开旧文件不会自动刷新。

## 数据契约

顶层结构：

```json
{
  "indices": [ { "key": "000985", "name": "中证全指", "stats": {}, "by_window": {}, "series": {}, "log": [] } ],
  "tiers": [ { "max": 20, "label": "极端便宜", "action": "加仓区", "color": "#1b7f4b" } ],
  "tier_colors": { "极端便宜": "#1b7f4b" },
  "confirm_ey_pct": 40
}
```

`indices[0]` 是主指数（默认中证全指），也是页面首次渲染的对象。

### `stats`（当前快照）

| 字段 | 类型 / 单位 | 含义 |
|---|---|---|
| `asof` | `YYYY-MM-DD` | 指数数据最后一个交易日 |
| `updated` | `YYYY-MM-DD HH:MM` | 页面生成时间 |
| `erp_bp` | int，bp | 最新 ERP |
| `tier` | string | 当前 10 年分位档位 |
| `verdict` | string | 完整结论句（双确认/单边/中性/偏贵） |
| `change_1w` | int，bp | 较约 5 天前的变化；样本不足时为 `0` |
| `y10` | float，% | 最新 10 年期国债收益率 |
| `y10_prev` | float / null，% | 上年最后一个交易日的利率 |
| `y10_ytd_bp` | int / null，bp | 利率较年初变化 |
| `y10_prev_date` | `YYYY-MM-DD` / null | 年初基准日 |
| `ey` | float，% | 指数收益率 = 100 / PE |
| `pe` | float | 指数 PE |
| `close` | float | 指数收盘点位 |
| `pct_ey_10` | float，% | 收益率 10 年分位（备用） |
| `cheap` | int，bp | 全样本 ERP 80% 分位 → 加仓线 |
| `rich` | int，bp | 全样本 ERP 20% 分位 → 防守线 |

空值规则：`y10_prev`、`y10_ytd_bp`、`y10_prev_date` 可能为 `null`（无上年数据），前端显示 `—`；其余字段始终有值。

### `by_window`（五档预计算）

键固定为 `"1" / "3" / "5" / "10" / "0"`，`"0"` 表示全部样本。

```json
{
  "erp_pct": 14.9,
  "ey_pct": 51.3,
  "tier": "极端便宜",
  "verdict": "单边便宜 · 相对债券便宜，绝对估值未跟上",
  "color": "#1b7f4b",
  "bg": "#1b7f4b14",
  "border": "#1b7f4b55"
}
```

| 字段 | 含义 |
|---|---|
| `erp_pct` | ERP 在该窗口的便宜度分位（越低越便宜） |
| `ey_pct` | 指数收益率在同一窗口的分位 |
| `tier` | 按 `erp_pct` 命中的档位 |
| `verdict` | 该窗口下的短结论，直接显示 |
| `color` / `bg` / `border` | 档位色及其 8% 底、33% 边框 |

页面不重新判定结论：切窗口只是读取对应键。前端只按 `pct` 再查一次 `tiers` 决定卡片着色。

### `series`（日频序列）

所有数组等长、按日期升序，索引一一对应：

| 字段 | 单位 | 说明 |
|---|---|---|
| `dates` | `YYYY-MM-DD` | 交易日 |
| `erp_bp` | int，bp | ERP |
| `y10` | float，% | 10 年期国债收益率 |
| `ey` | float，% | 指数收益率 |
| `close` | float | 收盘点位 |
| `pe` | float | 市盈率 |

### `log`（周度台账）

每行来自 `data/weekly_log.csv`，已按当前指数过滤并取最近 `recent_weeks`（默认 12）周：

| 字段 | 单位 | 说明 |
|---|---|---|
| `date` | `YYYY-MM-DD` | 当周最后交易日 |
| `y10` | % | 无风险利率 |
| `ey` | % | 指数收益率 |
| `erp_bp` | bp | ERP |
| `pct5y` / `pct10y` | % | 5 年 / 10 年便宜度分位 |
| `pct_ey10y` | % | 收益率 10 年分位（页面暂不展示，保留） |
| `tier` | string | 按 10 年分位定档 |

### 顶层共享字段

- `tiers`：来自 `config.yaml` 的 `signal.tiers`，顺序即配色顺序。
- `tier_colors`：档位名 → 颜色，台账信号胶囊用。
- `confirm_ey_pct`：双确认阈值，页脚文案用。

## 计算契约

### 基础公式

```text
指数收益率 ey%   = 100 / PE
ERP（bp）        = (ey% − 10Y国债收益率%) × 100
```

### 便宜度分位

```text
pct(window) = 窗口内 ERP > 当前 ERP 的交易日占比 × 100
```

- 窗口按自然年回溯（1/3/5/10 年），"全部" 用完整样本。
- 数值越低越便宜；前端文案必须写「比现在更便宜的天数」，避免被读成跌幅。
- 周报固定用 10 年；页面默认 5 年。

### 参考线与区间底色

- `cheap` = **全样本** ERP 的 80% 分位；`rich` = 全样本 20% 分位。不随所选指数窗口变化。
- 加仓底色：ERP ≥ `cheap` 的连续交易日；防守底色：ERP ≤ `rich` 的连续交易日。
- 连续段间隔 ≤6 个交易日先合并，再丢弃不足 5 个交易日的碎片，避免噪声竖条。
- 区间背景是独立 series，保证图例可单独开关。

### 结论判定

输入是同一窗口的 `p_erp` 与 `p_ey`：

| 条件 | 结论 | 双确认 |
|---|---|---|
| `p_erp ≤ 40` 且 `p_ey ≤ confirm_ey_pct` | 双确认 · 便宜且估值配合 | 是 |
| `p_erp ≤ 40`，估值不低 | 单边便宜 · 相对债券便宜，绝对估值未跟上 | 否 |
| `p_erp ≥ 60` 且估值不低 | 双确认 · 偏贵 | 是 |
| `p_erp ≥ 60`，估值也低 | 债券更有吸引力 | 是 |
| 其余 | 中性 · 两个口径都不极端 | 是 |

### 周变化与利率年初变化

- `change_1w` = 最新 ERP − 最近一个 ≤（最新日 − 5 天）的交易日 ERP；不足 6 行时为 `0`。
- `y10_ytd_bp` = 最新利率 − 上年最后一个交易日利率，再 ×100 转 bp。

### 台账写入

- 每次运行把主指数当天快照 upsert 进 `data/weekly_log.csv`；同一 `(index, date)` 保留最新。
- 首次运行或旧文件缺 `index` 列时，用最近 12 个周五回填各指数。
- 页面只读，不写台账。

## 文案与配色

### 文案

- ERP 单位统一 `bp`，整数；收益率、利率两位小数；分位一位小数；PE 两位小数。
- 变化值带符号：`+8bp` / `-8bp` / `0bp`；利率变化只陈述，不加「利好/利空」。
- 副标题固定包含：口径、`数据截止 <asof>`、`每周六 10:00 自动更新`。
- 分位卡说明必须带窗口名：`近五年窗口 · 比现在更便宜的天数`。
- 结论卡文字来自 payload，不在前端拼接判断。

### 颜色语义

| 元素 | 规则 |
|---|---|
| ERP 卡 | 白底，不着档位色 |
| ERP 较上周 | 走高（股票更便宜）绿 `#2e7d5b`，走低红 `#c0392b`，持平灰 |
| 利率 | 不染色，只显示数值 |
| 三张分位/判断卡 | 底色 `档位色 + 14`，边框 `+55`，数值用档位色 |
| 档位色 | 绿 = 便宜、黄 = 中性、橙红 = 贵；取自 `config.yaml` |
| ERP 折线 | `#e8833a`；指数 `#a8a49c`；利率 `#7d9db5` |
| 加仓带 / 防守带 | 绿 `rgba(27,127,75,.07)` / 红 `rgba(192,57,43,.07)` |

## 边界

### 为什么不用倍数

倍数 = 股权收益率 ÷ 国债收益率，问题在分母：

- 2019 年底以来倍数从 1.96 涨到 3.75（×1.91），其中 **利率贡献 103%、盈利收益率 −3%**。
- 同样的 6.02% 收益率，2014 年（国债 4.64%）对应倍数 1.30，今天（1.60%）对应 3.75。
- 现在 10bp 的利率变动会让倍数跳 6.2%（2014 年只有 2.4%）。
- 倍数分位混入高利率时代，天然显得「现在极度便宜」。

ERP 可加、可归因（`ΔERP = Δ收益率 − Δ利率`）、不会发散。用未来 12 个月收益做秩相关检验：全样本 IC 0.50 vs 倍数 0.39。

### 已知差异与补充方案

中证官网 `peg` 字段实为 PE，与银行口径不同，倍数绝对值差约 0.5，但分位几乎一致；ERP 用收益率差值，受影响更小。

- 处理原则：以**分位 + 方向**作为决策依据，绝对值仅作参考。
- 不同 PE 口径的 ERP 绝对值不可跨源比较；指数之间只看分位。
- 中证红利 ERP 可能近 1000bp、科创50 只有几十 bp，这是分母与成分差异，不是套利空间。

创业板指（399006）仍缺：中证官网 `index-perf` 返回空，免费源的日频 PE 不稳定。补充路径：① 接 Tushare `index_dailybasic`（需 token）；② 提供日频 PE CSV 挂进配置。

**已替代方案 —— 创业板50（399673）**：与创业板指不同，用创业板50 作对比观测（已在 `config.yaml` 注册，标签名「创业板50」，务必与创业板指区分）。数据源与推算口径：
- 该指数属国证/深证体系，中证 `index-perf` 无数据；乐咕乐股 `index-basic-pe` 只给**月频**整体法静态 PE（`lyrPe`），腾讯日线 `stock_zh_index_daily_tx` 给**日频**收盘价。
- 两者收盘价同口径（锚点日完全一致），故 `PE(t) = 月频PE(最近锚点) × 收盘价(t) / 收盘价(锚点日)` 把月频插值为日频；锚点日推算值与原始月频 PE 偏差为 0。样本自 2014-06-18（指数发布）起。
- 实现在 `fetch_pe_cyb50()`，由 `config.yaml` 的 `source: cyb50_lg` 触发；`--no-fetch` 时读 `data/pe_399673.csv`。
- 口径差异：整体法静态 PE 与中证 `peg` 不完全一致，且创业板50 盈利收益率常年偏低（PE 高），ERP 可能为负（如 2026-11-17 为 −2bp）——这是风格差异，不是套利信号。指数之间只看分位。
- 局限：月频 PE 锚点之间用价格插值，成分股调整带来的 PE 跳变只能在月末反映；上游限流时可能取数失败并跳过该指数。

### 局限

- 单一指标，不替代仓位管理与风险预算。
- 分位对窗口敏感，5 年与 10 年可能给出不同结论。
- 400bp 绝对线随利率中枢下移会逐渐弱化。
- 免费数据源无 SLA，仅适合个人监控。
